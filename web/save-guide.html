Save converter

Save converter guide

Convert a save between the original and translated game, change selected names and download the result.

Using the Save converter

  1. Choose conversion or Rename only.
  2. Choose the names’ game and language. For conversion, choose the games to convert between.
  3. Load a save. Its input format is detected automatically.
  4. Edit the names you want to change.
  5. Select an output format or keep the original format and extension.
  6. Download the new file separately; the original file stays as it is.

Names must fit their fields in characters the selected game supports; eggs cannot be renamed.

Only custom Pokémon nicknames are editable; default species names convert automatically.
