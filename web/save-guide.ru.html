Конвертер сохранений

Руководство по конвертеру сохранений

Конвертируйте сохранение между оригинальной и переведённой игрой, измените нужные имена и скачайте результат.

Использование конвертера сохранений

  1. Выберите конвертацию или режим Только переименование.
  2. Выберите игру и язык имён. Для конвертации выберите игры, между которыми она выполняется.
  3. Загрузите сохранение. Формат исходного файла определяется автоматически.
  4. Измените нужные имена.
  5. Выберите формат результата или оставьте исходные формат и расширение.
  6. Скачайте новый файл отдельно; исходный файл остаётся как есть.

Имена должны помещаться в поля и состоять из символов выбранной игры; яйца переименовать нельзя.

Можно изменить только клички покемонов; названия видов переводятся автоматически.
